نظام حسابات مدرسة مكارم الأخلاق + قسم الامتحانات

التشغيل:
1) npm install
2) npm start

اختبار الواجهات الأساسي:
npm run test:e2e

يستخدم الاختبار بيانات الدخول الافتراضية (yaghoub / 36485606). إذا تم تغييرها، يمكن تمريرها عبر E2E_USERNAME و E2E_PASSWORD.

الخادم المحلي:
npm run server

الامتحانات:
- الامتحان الأول والثاني والثالث.
- قوالب مواد مستقلة حسب القسم/الشعبة.
- ابتدائي: مادة + نتيجة.
- إعدادي/ثانوي: الاختبارات + الامتحان + الضارب + المجموع (الامتحان × الضارب).
- ملاحظات وقرارات قابلة للتخصيص حسب المعدل.
- كشف نتائج للطباعة مع رأس قابل للتعديل.
- الرأس: الجمهورية، الوزارة، الإدارة الجهوية، اسم المدرسة، هاتف المدرسة، العام الدراسي.
